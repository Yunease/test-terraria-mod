# Starforged Weapons —— 泰拉瑞亚 Mod

> 一个为 tModLoader 1.4+ 开发的极简武器 Mod，包含 5 把覆盖游戏各进度的原创武器。

## 项目简介

本项目是笔者独立开发的泰拉瑞亚（Terraria）模组作品，基于官方 Mod 加载器 tModLoader。Mod 的主题为「陨星锻炉」，新增了 5 把与原版进度相匹配的武器，每把武器均复用游戏原版弹幕并重新调整数值，保证与原版平衡体系兼容。

## 技术栈

- C# / .NET 6
- tModLoader 1.4+ API
- 使用 `Terraria.ModLoader`、`Terraria.ID` 等官方 API 实现物品、配方、本地化

## 主要实现内容

- 5 把可合成武器，覆盖游戏前中后各个阶段
- 每把武器独立配置伤害、击退、攻速、稀有度、合成配方
- 复用原版弹幕（木箭、钻石法球、子弹、泰拉光束等），避免额外美术与粒子资源
- 使用 tModLoader 新版本地化系统（`Localization/en-US.json`）
- 使用 RecipeGroup 兼容魔矿/猩红锭的合成替代

## 关于美术素材的说明

由于本项目历时较长（最初版本好像是2023年做的），在迁移与备份过程中，最初的绘制的美术素材不慎丢失。为了保证功能完整性与可运行性，当前仓库中的武器贴图为临时占位用的纯色块，Mod 的核心逻辑、配方、数值与本地化均已完成并可正常编译运行。后续只需替换 `Content/Items/Weapons/` 下的同名 `.png` 文件，即可恢复完整视觉效果，无需改动任何代码。

## 如何运行

1. 安装 tModLoader 1.4+（Steam 版）
2. 将本项目文件夹复制到 tModLoader 的 ModSources 目录下
3. 在 tModLoader 主菜单选择 **开发中的 Mod** → 找到 **Starforged Weapons** → 点击 **构建**
4. 构建成功后，进入游戏即可在物品栏或合成栏中测试武器
